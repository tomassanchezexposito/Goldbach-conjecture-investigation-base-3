# Lean 4 / mathlib formalization

This directory is reserved for checked Lean 4 and mathlib proofs.

Initial targets:

1. Formalize the three-case statement and the residual set H.
2. Prove algebraic equivalence of the reflected-doubles equation and the prime-pair sum.
3. Formalize the reflection map on indices of odd integers 3 + 2a.
4. Prove elementary modular-wheel counting identities, where mathlib supports them.

**No formal Lean proof has been completed or checked in this repository yet.** Do not mark Lean targets as done until files compile in a pinned Lean/mathlib environment and CI has succeeded.
