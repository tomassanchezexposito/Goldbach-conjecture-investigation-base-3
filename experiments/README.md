# Experiments

This directory will contain reproducible numerical experiments on prime positions, wheel-210 normalization, and higher-order prime correlations.

For every experiment, provide:

- A clear statement of the tested hypothesis.
- Parameter bounds and the primality-checking algorithm.
- A command that reproduces the output.
- Exact arithmetic or numerical error bounds.
- Independent tests for crucial claims.
- A plain statement that finite data do not prove universal coverage.

The initial small reference tests live in the tests/ directory. Larger datasets should not be committed without assessing repository size and provenance.
