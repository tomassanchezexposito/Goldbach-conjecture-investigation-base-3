# Results and verification certificates

Store only results with traceable inputs, methods, and verification status.

Each result should include:

- The exact theorem/claim or experiment identifier.
- Proof or computational classification.
- Assumptions and relevant domain or parameter limits.
- Program source and invocation instructions.
- Version information and SHA-256 digests for substantial input data.
- Independent verification details.
- Explicit limitations and unresolved obligations.

**Universal coverage remains unproved.** Empty or successful finite test sets are not evidence of a universal theorem.
