## Source intake checklist

For each historical report or dataset:

1. Record the original filename, stage number, and source location.
2. Compute and store a SHA-256 digest.
3. Preserve the original file without silent edits.
4. Extract and list the exact mathematical claims and hypotheses.
5. Classify each claim with the protocol in research_protocol.md.
6. Reproduce finite calculations and flag any uncertainty or contradiction.
7. Link validated claims into research_roadmap.md and the relevant formalization files.

Do not import an entire set of previously generated claims as verified merely because an earlier report describes them as theorems.
